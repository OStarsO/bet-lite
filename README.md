## 这是什么

「赌注 BETA」是一个**单人/局域网**的赌博小游戏合辑。你带着一笔随机本金（200~500w）进场，在三个玩法里周转，钱可以存进银行吃利息、可以从商店买道具、也会被一套阶梯税慢慢抽走——目标是别破产，顺便体验一把"越来越难"的经济曲线。

界面是深色液态玻璃风（glassmorphism），骰子有 3D 掉落动画，轮盘是 3D 旋转的，赢钱时屏幕底部会掉金币和表情雨。

> 金额单位统一是 **w**（万）。比如 `500w` = 500 万。

- Windows / macOS / Linux 桌面环境


- 左下角/设置页可以打开**系统控制台**（修改器）

## 三种玩法

### 🎲 单机骰子

最基础的玩法：你和电脑各摇一颗骰子，**点数大者赢**，平局退回赌注。

1. 先选**房间**（房间有资产门槛，也有"黑招"）
2. 输入赌注 → 点「🎲 摇骰子」
3. 看 3D 骰子从空中落下、弹跳、停在你的点数上

| 房间 | 门槛 | 特殊规则 |
|---|---|---|
| 初级房 | 0 | 无 |
| 中级房 | 50w | 无 |
| 高级房 | 100w | **险招 25%**：你领先时，有 25% 概率被翻盘 |
| 大师赛 | 1000w | **险招 40%** + **压制**：平局时电脑直接 +1 |

> 「险招」只在正常掷出的情况下生效；如果你用了出千卡/稳胜卡锁定了胜局，就不再干预。

### 🎡 欧式轮盘

标准欧式轮盘，37 个号码（0~36）。选筹码 → 点赌桌格子下注 → 点「🎡 旋转」。

| 注项 | 赔率（不含本金） |
|---|---|
| 直注（单个数字） | 35 : 1 |
| 红 / 黑 / 奇 / 偶 / 大(1-18) / 小(19-36) | 1 : 1 |
| 打（dozen 1/2/3）/ 列（col 1/2/3） | 2 : 1 |

- 轮盘是 3D 的，没有指针——**结果看白色小球停在哪**
- 小球落点**每局完全随机**（覆盖整个盘面 0~360°）
- 设置里有个「🎡 轮盘 · 落点提示」开关（默认关）：只控制要不要画那个**黄色落点提示圈**，不影响小球落点

### 🃏 炸金花（三张牌）

你和电脑各 3 张牌比大小，赢家通吃底池。

**牌型大小**（从大到小）：

```
豹子   三张同点        AAA > KKK > ... > 222
顺金   同花顺          AKQ 最大，A23 最小
金花   同花非顺
顺子   不同花顺子       AKQ 最大，A23 最小
对子   两张同点
单张   散牌
特殊 235   不同花的 2-3-5，可以吃豹子（本玩法最有名的规矩）
```

**一局流程**：

```
下底注 →【加注 / 开牌 / 弃牌】→ 逐张揭示 → 比大小 → 结算
```

- **加注**：电脑按牌力和底池比例决定跟还是弃；电脑弃牌你直接收池。单局最多加注 4 次
- **开牌是逐张揭示的**：点「开牌」后进入揭示阶段，每次点「继续开牌」亮一张，**你亮第 N 张，电脑跟着亮第 N 张**，第 3 张全亮才比大小
- **中途退出换牌**：揭示过程中觉得比不过，可以点「🔄 退出换牌」——费用 = **你这局已经投进去的钱**（下 100w 就收 100w），然后立即重新发牌开新局

## 经济系统：银行 / 商店 / 税

### 🏦 银行

- **存款**吃利息，每局结算；基础利率 2%，VIP 等级有加成，计息基数有上限防爆炸
- **贷款**：借一笔钱，**10 局后要还 150%**；还不上进违约冷却（5 局）
- 破产不会死锁：有保底可贷额度 `100w`，破产弹窗可以直接重开新局

| VIP 等级 | 总资产门槛 | 利率加成 | 贷款倍率 |
|---|---|---|---|
| 🥉 青铜 | 0 | — | ×0.5 |
| 🥈 白银 | 1000w | +0.5% | ×0.7 |
| 🥇 黄金 | 5000w | +1.0% | ×1.0 |
| 💎 钻石 | 20000w | +1.5% | ×1.5 |
| 👑 王者 | 100000w | +2.0% | ×2.0 |

### 🛒 商店

500w 一张的出千卡、300w 的保命符……每 **5 局**有 30% 概率刷一次折扣（-10% ~ -50%）。

| 道具 | 价格 | 效果 |
|---|---|---|
| 🔍 出千卡 | 500w | **消耗品**：本局胜率 +10%，用完扣 1 张；最多叠 5 张（+50%） |
| 🛡️ 保命符 | 300w | 下一局输了不扣钱 |
| 💰 财运符 | 800w | 下一局赢了双倍收益 |
| 🎯 稳胜卡 | 2000w | 3 局内每局 50% 概率直接掷出必胜 |
| 💎 贵宾卡 | 5000w | 永久贷款额度 ×2 |

> 出千卡的胜率加成是**精确的 +N 个百分点**（不是"N% 概率必胜"）：5 张时基础胜率 41% → 91%，每张正好 +10pp。

### 🧾 全局阶梯税

这是后期最大的压力来源。**每 10 局收一次税，税额 = 当前回合数，10000w 封顶**：

| 回合 | 税 |
|---|---|
| 第 10 局 | 10w |
| 第 20 局 | 20w |
| 第 50 局 | 50w |
| 第 100 局 | 100w |
| 第 1000 局 | 1000w |
| 第 10000 局 | **10000w（封顶）** |
| 第 10010 / 10020 / … 局 | 一直 10000w |

骰子、轮盘、炸金花**每打完一局都收**。控制台 `status` 能看到「下次收税：第 N 局 · Xw」。

## 存档说明

- 存档文件是根目录的 **`save.dat`**，加密格式为 **XOR + HMAC-SHA256**
- 默认密钥写死在代码里；执行 `setkey` 后会生成 **`key.dat`**，之后用它加密（`resetkey` 可恢复默认）
- **自动备份**：每次存档前会把上一版好档复制到 `save.dat.bak`；主档损坏时自动回退，`has_save()` 也认备份
- 每局结束、关窗口时都会自动存档，也可以随时 `save`

```

├── main.py              入口：pywebview 窗口 + 版本号唯一来源
├── backend/
│   ├── state.py         全局状态、常量表（VIP/商店/房间）、reset()
│   ├── api.py           暴露给前端的接口（window.pywebview.api.xxx）
│   ├── dice.py          骰子结算（道具 → 房间难度 → 修改器胜率 → 结算）
│   ├── roulette.py      欧式轮盘逻辑 + 3D 角度计算
│   ├── jinhua.py        炸金花纯逻辑（牌型 / AI / 逐张揭示 / 退出换牌）
│   ├── bank.py          银行：VIP、利息、贷款
│   ├── shop.py          商店道具 + 折扣
│   ├── save.py          XOR+HMAC 存档、.bak 备份
│   └── net.py           联机（TCP 25565 / UDP 发现 25566）
├── ui/
│   ├── index.html       页面结构
│   ├── css/app.css      液态玻璃样式
│   └── js/app.js        前端逻辑（骰子动画 / 轮盘3D / 金币物理 / 控制台…）
└── .workbuddy/shots/    测试脚本与截图
```

### 联机对战

- 支持 2~4 人局域网，TCP 端口 `25565`，UDP `25566` 自动发现
- **房主只主持、不参与下注**；所有玩家下注后自动开摇，点数最大者赢，赢家平分所有输家的注，资金归零即出局
